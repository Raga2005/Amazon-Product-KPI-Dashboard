# Amazon Product Performance Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze Amazon product data. The dashboard provides insights into product performance, customer ratings, reviews, discounts, and category-wise trends to support data-driven decision-making.

## Objectives

* Analyze product ratings and customer reviews.
* Identify top-performing product categories.
* Compare discounts across categories.
* Visualize key product performance metrics.
* Build an interactive dashboard using Power BI.

## Dataset

The dataset contains Amazon product information, including:

* Product Name
* Category
* Actual Price
* Discounted Price
* Discount Percentage
* Rating
* Rating Count
* Customer Reviews

## Key Performance Indicators (KPIs)

* Total Products
* Average Rating
* Average Discount Percentage
* Total Reviews

## Dashboard Visualizations

### 1. KPI Cards

* Total Products
* Average Rating
* Average Discount
* Total Reviews

### 2. Category Analysis

* Product Count by Category
* Average Rating by Category
* Average Product Price by Category

### 3. Customer Review Analysis

* Top 10 Most Reviewed Products

### 4. Interactive Filter

* Category Slicer
